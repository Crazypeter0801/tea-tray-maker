# 从用户描述到可打印几何

每次新设计或主要造型变更时读取。目标是把意图落实为当前项目的参数化源码和实际模型；历史茶盘只提供处理问题的方法。

## 解释需求，不替用户选历史模板

将一句话拆成五类，已有信息直接使用，未明确项保留为可修改假设：

| 需求层 | 转成什么几何或检查 | 容易误解的地方 |
| --- | --- | --- |
| 外形：圆润、叶片、云朵、不规则 | 平面闭合轮廓、局部圆角与内缩边界 | 装饰主题不一定意味着外形也相同 |
| 使用：一杯、双杯、紧凑、好拿 | 杯底/杯腹/把手占位、可用区域、取放余量 | 外包围盒能容纳不代表角落或凹口能容纳 |
| 储水：更深、易倒水、好清洗 | 底厚、承杯高度、围边高度、沟槽连通与出口 | “更深”不能自动解释为减薄底板 |
| 风格：流动、疏朗、均匀、带标记 | 曲线走向、密度、净沟宽、留白域及标记位置 | “均匀”可能指净间距而非中心距 |
| 制作：指定机型、尺寸、材料 | 成品包络、打印方向、薄壁与实际切片路径 | 不用缩放 STL 来适配打印机而连带改变壁厚 |

例如“像一片叶子，放两个杯子，纹路柔和”应先考虑叶形外轮廓、两杯布局和顺叶脉方向的线族；不能只在矩形波纹盘上加一片叶子。若用户只说“叶子主题”，可简短说明拟采用的解释，必要时确认外形还是装饰。

## 将构图拆成可替换的几何层

在项目源码中分别表达：外轮廓、内壁/储水域、杯具布局、主图案、背景线族、留白区域和边缘处理。参数按实际设计组织，无需强行采用固定函数名。

- 规则轮廓用直线、圆弧和约束；有机轮廓用少量受控样条或用户矢量。封闭、方向一致、无自交后再挤出。
- 对凹轮廓内缩时检查分裂、消失或尖角，不假设每个轮廓都能通过同一半径得到合法内壁。必要时局部改曲线或构造内轮廓，说明影响。
- 根据杯具足迹安排承杯区，再设计纹理。纹理方向随主题选取，可以是直线、环、流线、图案线或组合；不要强制波纹。
- 纹理中心线转实体时独立控制筋宽、净沟宽、承杯高度；裁切到可用域并融合到底板。背景避让主图案的完整包络，是否填入内部空白由设计决定。
- 维护外壁厚度、底厚、纹理宽度和不同倒角各自的参数，避免改一处波及其他部分。

先生成可检查的基础体，再添加纹理与圆角。每一层都检查所需特征是否存在，复杂布尔除了有效性还应检查实体数和体积变化。有效的“空盘”不能代替丢失装饰的定制成品。

## 将多轮修改翻译成局部操作

每轮记录采用版本、用户要求的变化、保持项和待验证项；保存可回退的源码及导出物。使用同视角的实际模型预览比较改前改后。

| 用户反馈 | 优先检查或修改 | 同时复查 |
| --- | --- | --- |
| 曲线不顺、这里有钩 | 局部切线/曲率、连接段和邻线走向 | 识别特征、筋宽、相邻净间距 |
| 留白太多、想更密 | 指定区域线族的数量或间距 | 杯脚支撑、清洁沟、图案是否仍清楚 |
| 两边缝不一样 | 从真实边界分别测量两端退让 | 避免一端贴死的 T 接头 |
| 边缘不整齐 | 延长近边筋后按等距内边界统一裁切 | 内部装饰端头不应一起延长 |
| 圆角处有碎片 | 裁切边界与线族的相对位置、短薄轮廓 | 倒角是否真的完成，不能静默回退锐边 |
| 杯子不稳 | 实际杯脚在指定摆位的接触分布 | 图案留白和用户是否接受加筋 |
| 储水更多 | 按用户意图调整承杯面/围边高度 | 刚度、溢水余量、排水连通及容量 |

先修局部原因，不重做用户已认可的全盘。数值更好不自动等于设计更好：加筋、填白等影响外观时展示变化供选择；被否决的改法保留原因，不能在后续自动恢复。

## 交付验收从需求开始

将用户的关键描述逐项与实际模型对应，例如“叶形外沿已实现”“两杯摆位基于假设直径，待确认”“承杯面保持同高”。几何通过之外，还要检查所要的形状、装饰与版本选择是否真正保留。

交付当前构图的可编辑源码和 STEP/STL、实际模型预览、验证记录。默认波纹脚本的测试只证明该脚本及检查器，不能当作新轮廓已验证的证据；新造型必须实际生成并检查，切片和试印状态另列。
